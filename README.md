🏛️ System Architecture: The Four Core Pillars
1. The Citizen Reporting Gate (Intake Layer)
A high-efficiency, zero-friction mobile web application that allows citizens to capture and flag municipal infrastructure failures in real time.
Automated Telemetry: Silently initializes and locks high-accuracy GPS coordinates via satellite triangulation onto the page background the exact millisecond the application mounts—requiring zero extra clicks from the user.
Local Memory Isolation: Implements client-side binary buffering (URL.createObjectURL), allowing citizens to instantly snap camera photos and preview them without consuming cellular data or making premature API requests.
Atomic Fail-Safe Submissions: Executes an all-or-nothing database transaction that concurrently streams raw media binaries into cloud storage buckets, generates public CDN pathways, and creates database records mapped to dual-synchronized access keys (image_url and photo_url) to prevent data pipeline drops.


2. The Biometric Cryptographic Shield (Access Layer)
An enterprise-grade administrative authentication gateway that completely replaces vulnerable passwords with local device hardware verification.
Anti-Replay Handshake: Before initializing device hardware sensors, the server issues a cryptographically randomized, single-use server challenge vector.
WebAuthn Passkey Protocols: Features client-side exception filtering to handle embedded browser frame restrictions while utilizing secure Base64URL payload packaging to seamlessly register local biometric keys (Apple TouchID, Windows Hello) to database records.
Zero-Trust Server Validation: Instead of trusting client side entry flags, a serverless runtime decrypts, processes, and verifies the cryptographic public-key assertion signature before unlocking dashboard systems.


🤖 3. The Forensic AI Auditor (Verification Pipeline)
The core engine of the platform that acts as an automated municipal inspector to verify contractor work quality before public funds are dispersed.
Serverless Orchestration: When a repair contractor uploads a photo to close a ticket, the system freezes the interface and dispatches an authorized handshake to a Supabase Edge Function runtime environment.
Multimodal Vision Verification: Streams both the citizen's original "Before" evidence photo and the contractor's "After" repair photo as binary data arrays directly into a secure Google Gemini Vision API invocation.
Geospatial & Topographical Auditing: The AI performs two strict, non-bypassable programmatic reviews:
Landscape Fingerprinting: Compares fixed physical landmarks (building outlines, horizon thresholds, telephone poles, wall textures) to ensure the contractor is standing at the exact same physical coordinates as the reporting citizen.
Defect Remission Check: Analyzes the cavity depth of potholes or dimensions of waste piles to guarantee the hazard has been completely cleared or resurfaced cleanly.

📊 4. The Immutable Civic Audit Trail (Transparency Layer)
A ledger module that visually documents verified municipal resolutions for public tracking and institutional reporting.
Closed-Loop Verification: Displays citizen report and municipal solution media cards side-by-side over secure resolution timestamp strings.
Dynamic Analytics Sync: Directly keys into relational table variables to calculate and display the data metric panels tracking the issue's priority rating (S-Score), public community upvotes, and the exact integrity metric parsed from the AI vision verification analysis response.
